## Формат

1. Заголовок Дзена — из названия основной статьи (можно чуть короче, смысл тот же).
2. Ровно **три** картинки — это **фото**, не инфографика:
   - главная (обложка) сразу после начала, токен `DZEN_COVER_PLACEHOLDER`;
   - две в тексте: `DZEN_IMAGE_PLACEHOLDER_1` и `DZEN_IMAGE_PLACEHOLDER_2`.
3. В markdown: `![<сцена по заголовку статьи>](DZEN_COVER_PLACEHOLDER)`.
   Alt каждого кадра — предмет, место или результат из темы статьи, без людей, три
   разные сцены, не схема. Не заменяй токены на URL.
4. Короче основной статьи. Без FAQ-простыни, без длинных таблиц, без CTA сайта.
5. Не копируй абзацы дословно — сожми своими словами, факты оставь.

## Output contract

Return ONLY valid JSON (no markdown fences, no commentary) with this exact shape:

{
  "title": "string",
  "content_markdown": "string",
  "char_count": 0
}
