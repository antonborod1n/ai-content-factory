## Задача

1. `verdict`: `ok`, если критичных проблем нет, иначе `needs_revision`.
   Если проблем нет — `issues` пустой список.
2. `issues`: только реальные проблемы. Для каждой:
   - `severity`: `error` или `warning`;
   - `claim`: коротко, что сказано в статье;
   - `problem`: почему это спорно;
   - `suggestion`: как исправить (смягчить, убрать число, опереться на базу).
3. Не придумывай новые факты. Не цитируй длинные абзацы.
4. `notes` — одна-две фразы для редактора.

## Output contract

Return ONLY valid JSON (no markdown fences, no commentary) with this exact shape:

{
  "verdict": "needs_revision",
  "issues": [
    {
      "severity": "warning",
      "claim": "string",
      "problem": "string",
      "suggestion": "string"
    }
  ],
  "notes": "string"
}
