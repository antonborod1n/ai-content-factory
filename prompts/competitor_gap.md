# Content gap — контент-план из инвентаря конкурентов

Собери улучшенный список тем статей из выгрузок конкурентов.

Домен: {{domain}}
Ниша: {{niche}}
Аудитория: {{audience}}
Гео: {{geo}}
Тип сайта: {{site_type}}
Язык: {{language}}
Максимум тем: {{max_topics}}

Сигналы (slug из URL и ключевые фразы, уже дедуп):

{{hits_json}}

Правила:

- Не копируй формулировки конкурентов дословно. Переформулируй сильнее: угол, ЦА, гео.
- Кластеризуй near-duplicates в одну тему.
- Must-have = сигнал у 2+ конкурентов. Gap = нужно ЦА/гео/коммерции, но почти ни у кого нет.
- Покрой конкурентов и добавь примерно 20–30% новых gap-тем.
- Не предлагай темы без информационного или коммерческого интента.
- Не делай темы, которые нельзя связать с продуктом, услугой или экспертизой
  сайта: у каждой темы должен быть понятный мост к предложению сайта.
- Не обещай медицинских, юридических или финансовых результатов, которые сайт
  не может гарантировать.
- `title` — готовый заголовок статьи на языке {{language}}.
- `priority` — High, Medium или Low.
- `competitors` — имена из сигналов; для новых тем пустой список и `isGap: true`.
- `uniqueAngle` — чем страница лучше конкурента.
- `intent` — informational / commercial / transactional плюс howto / compare / problem.
- `commercialLink` — конкретный раздел сайта по типу сайта: категория
  каталога, страница услуги, тариф, калькулятор или форма заявки. Без
  абстракций вроде «сайт компании».
- Верни не больше {{max_topics}} тем.

Ответ — только один валидный JSON-объект без блоков кода и комментариев:

{
  "topics": [
    {
      "title": "",
      "category": "",
      "priority": "High",
      "competitors": [],
      "isGap": false,
      "uniqueAngle": "",
      "intent": "informational / howto",
      "commercialLink": "",
      "format": "гайд"
    }
  ]
}
